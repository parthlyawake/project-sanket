# SANKET Tablet UI Frontend

This is the React tablet UI client for Project SANKET. It provides:
1. DPDP Act 2023 Consent Gating.
2. 60-Second Real-Time Scrolling Timeline Lanes (AUs, Gaze, Posture, Pulse).
3. Live Speaker Diarized Transcripts & Contradiction Alerts.
4. Vulnerable Safeguard Overlays.
5. Session Reports & PDF downloader.

## Build and Start

1. Install Node.js dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

3. Open the browser at `http://localhost:3000`. Ensure the backend server is running on `http://localhost:8000`.
